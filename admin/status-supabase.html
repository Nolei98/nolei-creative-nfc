Passo a Passo de Instalação (60 Segundos)
  1. Acesse supabase.com e crie um projeto novo gratuito.
  2. No painel do Supabase, clique em SQL Editor no menu lateral esquerdo.
  3. Copie o conteúdo de supabase/schema.sql do seu projeto, cole no editor e clique no botão verde Run.
  4. Vá em Project Settings > API e copie a Project URL e a anon public key.
  5. Cole essas duas chaves no arquivo js/nolei-config.js ou teste direto nesta tela!

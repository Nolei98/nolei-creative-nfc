Breve Descrição do Roteiro

O exame parcial consiste na demonstração prática e conceitual do projeto CIS (Customer Information System) em aproximadamente 16 minutos, evidenciando domínio das metodologias ágeis, arquitetura de software, automação de testes e execução ao vivo dos microsserviços.

CLI Application

users-cli

Interface em linha de comando desenvolvida para interagir com o ecossistema de usuários. Demonstração ao vivo dos comandos essenciais:

GET (Gabriel) POST (Gabriel) PUT (João) DELETE (João)
API Documentation & Testing

users-api Swagger

Documentação interativa OpenAPI/Swagger acessível via navegador para validação de endpoints e contratos de comunicação HTTP:

GET (João) POST (João) PUT (Bruna) DELETE (Bruna)
REST Backend Service

users-api

Serviço backend principal rodando na máquina. Resolve a lógica de persistência e regras de negócio com participação coletiva dos 4 integrantes:

GET (Gabriel) POST (João) PUT (Maria Beatriz) DELETE (Bruna)
